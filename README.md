## 🥗 Featured: Nomi

<a href="https://github.com/david-x3d/nomi">
  <img alt="Nomi: calorie tracking for Android" src="https://img.shields.io/badge/Nomi-Calorie%20Tracking%20for%20Android-0f172a?style=for-the-badge&logo=android&logoColor=3DDC84">
</a>
<a href="https://github.com/david-x3d/nomi/releases/latest">
  <img alt="Latest release" src="https://img.shields.io/github/v/release/david-x3d/nomi?style=for-the-badge&label=release&labelColor=111827&color=3DDC84">
</a>

**Nomi** is a native Android calorie and nutrition tracker, built around fast food logging, accurate nutrition data and a clean UI.

- **Fast logging:** researched food parsing, barcode support, Open Food Facts data, favourites and meal grouping
- **Progress:** history, progress tracking and home-screen widgets
- **Your data:** backups and an in-app update checker
- **For everyone:** localisation and accessibility support

<sub>Built with Kotlin · Jetpack Compose · Android</sub>

**[View the repo →](https://github.com/david-x3d/nomi)** &nbsp;·&nbsp; **[Download the latest release →](https://github.com/david-x3d/nomi/releases/latest)**
